# Kaigofukushishi Quiz Game

A simple browser quiz game built with HTML, CSS, and JavaScript.

## Features
- 125-question quiz flow
- Multiple-choice buttons
- Score tracking and progress display
- Result screen with restart option

## Run locally
1. Open `index.html` in your browser.
2. Click an answer for each question.
3. See your final score at the end.

## Customize
- The app now uses real 2026 第38回介護福祉士国家試験の問題 and answers.
- Edit `questions.js` to update or replace the loaded exam data.

## Notes
- This quiz app is built as a static browser game with the real exam content loaded from `questions.js`.
- Open `index.html` in a browser and answer the 125 questions.
